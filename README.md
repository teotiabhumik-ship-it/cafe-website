# ☕ Cafe ElleBee — Cozy Coffeehouse & Lounge Website

> Official modern website for **Cafe ElleBee**, located at B-19 Ground Floor, RDC, Raj Nagar, Ghaziabad.

Built with **React 19**, **Vite**, **Tailwind CSS**, **Framer Motion**, and **Lenis** smooth scrolling.

---

## 🌟 Key Features

* **Cozy & Warm Aesthetic:** Tailored espresso and warm amber color palette matching the real cafe's interior lighting and neon decor.
* **Separated Chapter Architecture:**
  * **The Sanctuary (Home):** Cinematic cover with kinetic text, rising steam animation, floating amber light motes, and interactive chapter doors.
  * **Artisan Menu:** Curated menu with live search, *Bestsellers Only* filter, category tabs, prices, and pure-veg indicators.
  * **The Space:** Visual editorial tour with photo categories, interactive lightbox, and Instagram reel integration.
  * **Celebrations:** Dedicated party booking lounge with transparent pricing packages (*Birthday Glow*, *Date Night*, *Friends Lounge*) and 1-tap WhatsApp inquiry.
  * **Find Us & Map:** High-contrast Google Maps embed, 1-click cab address copy, live opening hours, and verified Google reviews.
* **Motion Graphics & Physics:**
  * **Lenis:** Buttery inertial smooth scrolling.
  * **Interactive Amber Light Cursor:** Desktop spring-physics glow following mouse movements.
  * **AnimatePresence:** Seamless chapter view transitions with subtle blur and slide easing.
  * **Celebration Confetti:** Interactive party booking confirmation with confetti bursts.
* **Direct Actions:** One-click table reservation via WhatsApp, direct phone calling, and delivery links for Swiggy & Zomato.

---

## 🚀 Tech Stack

* **Framework:** React 19 + Vite 8
* **Styling:** Tailwind CSS v4
* **Motion & Animations:** Framer Motion + Lenis Smooth Scroll + Canvas Confetti
* **Icons:** Lucide React + Custom SVGs
* **Typography:** Cinzel & Plus Jakarta Sans

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/teotiabhumik-ship-it/cafe-website.git
cd cafe-website

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
